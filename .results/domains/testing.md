# Testing Domain Analysis

## Overview

Testing uses Vitest framework with React Testing Library for component testing. Tests are colocated with source files using .test.ts pattern with shared mock utilities.

## Testing Framework

### Vitest Configuration

Modern test framework with fast execution and comprehensive test coverage for critical paths.

### Component Testing

React Testing Library for component testing with accessibility testing using axe and mock utilities for external dependencies.

### Test Organization

Tests colocated with source files and isolated from external state for maintainability.

## Key Files

- `vitest.config.mts` - Test configuration
- `setupTests.ts` - Test setup utilities
- Test files throughout codebase with `.test.ts` pattern
